# SFCC Reviews Cartridge

An SFRA extension for customer ratings and written reviews, with authenticated submissions,
site-scoped custom objects, and Business Manager moderation.

The working implementation is being organized into five feature phases: foundation,
review storage, storefront, tooling and quality, and documentation. Each phase is
reviewed through its own pull request and merged into `main`.

SFRA-derived template attribution and terms are preserved in [NOTICE.md](NOTICE.md).
